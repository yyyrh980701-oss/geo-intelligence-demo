# GEO Introduction Page

Static product introduction page for external preview.

Open `index.html` directly, or publish this repository with GitHub Pages.

The public trial form works in static mode by creating and copying a structured trial brief. To collect submissions automatically, set `data-endpoint` on `#trialForm` in `index.html` to a form backend such as Feishu, Formspree, Zapier, or your own API.
